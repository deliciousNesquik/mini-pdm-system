# ADR 0007. Критерий «данные не изменились» при повторном импорте

Дата: 2026-10-02 Статус: принято

## Контекст

Повторный импорт различает Unchanged / Update / CreateNewVersion 
CadDocument это record, но record-равенство не сравнивает содержимое списков, 
а порядок компонентов в `JSON` семантики не несет.

## Альтернативы

- `Record Equals` не работает для состава, списки по ссылке.
- Атрибуты + состав как упорядоченный список то будут ложные новые версии из-за перестановки компонентов.
- Атрибуты + состав как мультимножество пар.

## Решение

Сравниваются наименование, материал, масса и состав как мультимножество по 
доменной идентичности потомка `ObjectIdentity.Key`, не по `id` БД.

## Последствия

- Обязательный тест тот же состав в другом порядке должен выдать Unchanged.
- Исполнение `Data` применяет решение `ReImportRules` и не дублирует сравнение.
