# ADR 0008. Политика циклических ссылок

Дата: 2026-10-02 Статус: принято

## Контекст

Техническое задание требует обнаружение циклов, а вот как обработать их - нет!

## Альтернативы

- Импортировать цикл и защищаться в расчетах, масса и рекурсивный `CTE` теряют семантику 
на цикле, guard-код расползается по всей системе. 
- Отклонять участников цикла каскадом по общему правилу.

## Решение

Участники цикла отклоняются с причиной цикл в отчете - одна каноническая цепочка, нормализованная к минимальному элементу. 
Сборки, ссылающиеся на отклоненных, отклоняются каскадом, как и для прочих ошибок.

## Последствия

В БД попадают только ациклические графы - guard-кода в CTE не требуется.
Цикл через невалидный промежуточный узел невозможен потому что узел уже отклонен.
