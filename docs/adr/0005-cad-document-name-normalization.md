# ADR 0005. Нормализация имен CAD-документов к NFC

Дата: 2026-10-01 Статус: принято

## Контекст

Идентификатор документа это имя файла. Имена на диске в разных файловых системах
хранятся в Unicode `NFC` каноничный вид один символ без дополнений/(`NFD` (й = и + U+0306)), 
значения `fileName` и ссылки в components внутри `JSON` - в `NFC`. Строки визуально идентичны, 
байтово различны, сравнение `.NET` рвет связи.

## Альтернативы

- Нормализовать в каждой точке сравнения имен - политика размазана, гарантий нет.
- Нормализовать в одной точке входа: адаптер приводит к `NFC` все, что кладет в `CadDocument`.
- Не нормализовать - на `Linux` импорт теряет компоненты сборок.

## Решение

Единственная точка нормализации - `MiniPdm.Cad.Json`. Форма - настройка адаптера, 
по умолчанию `FormC`, поменять на `FormD` - без правок кода выше адаптера. 
Файлы данных не изменяются никогда.

## Последствия

Код выше адаптера о проблеме не знает. Будущий адаптер **КОМПАС 3D** у которого идентификаторы - не файлы
отвечает за нормализацию сам.
