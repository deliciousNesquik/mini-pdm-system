# ADR 0006. Контракт ICadDocumentReader дополнен ListDocumentsAsync

Дата: 2026-10-01 Статус: принято. 
Расширяет контракт из ТЗ - сигнатуры менять разрешено с обоснованием.

## Контекст

ТЗ задаёт только `ReadAsync(path)`. Импорту нужно перечислить документы папки.
Перечисление файлов - работа с файловой системой. ТЗ требует, чтобы остальной код о ней не знал.

## Альтернативы

- `Directory.GetFiles` в сервисе импорта - утечка файловой системы выше адаптера.
- Расширить контракт методом перечисления.

## Решение

`ListDocumentsAsync` возвращает местоположения, пригодные для `ReadAsync` напрямую 
(файловый адаптер - полные пути), чтобы сервис импорта не собирал пути сам.

## Последствия

Тестовый fake реализует оба метода.
Будущий адаптер КОМПАС возвращает свои идентификаторы документов.
