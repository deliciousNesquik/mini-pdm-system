# ADR 0010. Ошибки чтения документа: исключение против результата

Дата: 2026-10-02 Статус: принято

## Контекст

Битый документ файл Отдушина имеет обрезанный JSON, неизвестный formatVersion, 
неизвестный type - документ не читается. Импорт при этом обязан продолжаться 
по остальным файлам, а причина должна попасть в отчет.

## Альтернативы

- ReadAsync возвращает Result<CadDocument, string> и отсутствие исключений, но контракт из ТЗ - Task, и try/catch-рутина расползается по сервису.
- ReadAsync бросает CadDocumentException сервис ловит ровно его и превращает в вердикт Ошибка с причиной - выбрано.

## Решение

Все сценарии нечитаемости — CadDocumentException с причиной:

- некорректный JSON включая обрезанный файл;
- formatVersion != 1;
- отсутствуют любые или все fileName/name/type + неизвестный type;
- fileName в JSON не совпал с именем на диске после нормализации идентификатор это имя на диске, JSON-поле информационное;
- IO ошибка чтения файла например перенесли или удалили.OperationCanceledException не перехватывается тогда отмена не свойство документа. 
- Бизнес-валидация масса, маска обозначения в ридер не входит потому что это зона ImportAnalyzer;ы

## Последствия

- Сервис импорта try/catch ровно вокруг ReadAsync, тип известен вердикт Ошибка отличим.
- Граница читаемости проверяется тестами на встроенных JSON-строках.

исключение здесь честнее, потому что документ не читается - это действительно исключительная ситуация
