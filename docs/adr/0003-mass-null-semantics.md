# ADR 0003. Семантика массы: NULL это «не задана», ноль запрещен

Дата: 2026-10-01 Статус: принято

## Решение

`mass_kg` NUMERIC(12,4), CHECK: NULL или > 0. Нулевая масса невозможна.

## Обоснование

По ТЗ деталь без массы импортируется с предупреждением,
а расчёт массы сборки должен назвать виновника, а не вернуть неполную сумму. 
Это требует различать данных нет и данные равны нулю. Если допустить 0, он неотличим от 
не задана и молча участвует в сумме. `NULL` это наш честный маркер отсутствия, пробрасывается 
до отчёта и UI: пустая масса в сводной спецификации.

## Последствия

В домене масса — `decimal?` а в расчётах отсутствие массы - не 0, 
а отдельная ветка с перечислением объектов без массы.
